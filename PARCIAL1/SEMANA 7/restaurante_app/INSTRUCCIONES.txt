⚙️ VALIDACIONES IMPLEMENTADAS
================================================================================

PRODUCTO:
  • Nombre: No puede estar vacío
  • Categoría: No puede estar vacía  
  • Precio: Debe ser mayor que cero
  • Precio: Debe ser un número válido (int o float)
  • Disponible: Debe ser booleano (True/False)

CLIENTE:
  • Nombre: No puede estar vacío
  • Correo: No puede estar vacío
  • ID: No puede estar vacío
  • ID: Debe ser único en el sistema

RESTAURANTE:
  • Productos: No permite duplicados por nombre
  • Clientes: No permite duplicados por ID
  • Búsquedas: Insensibles a mayúsculas

🎓 CONCEPTOS OOP DEMOSTRADOS
================================================================================

✓ CONSTRUCTOR (__init__)
  Inicializa objetos con datos validados
  Uso: Producto(nombre, categoria, precio)

✓ @PROPERTY y @SETTER
  Controlan acceso a atributos privados con validación
  Uso: producto.precio = 19.99

✓ @DATACLASS
  Genera automáticamente __init__ y otros métodos
  Uso: @dataclass class Cliente

✓ SERVICIOS (CAPA DE LÓGICA)
  Centraliza operaciones CRUD
  Uso: restaurante.registrar_producto(producto)

✓ ARQUITECTURA MODULAR
  Separación en capas: modelos, servicios, presentación
  Uso: from modelos import Producto

✓ VALIDACIÓN
  Garantiza integridad de datos desde entrada
  Uso: @setter con if/raise ValueError

✓ ENCAPSULACIÓN
  Atributos privados (_nombre) vs públicos (nombre)
  Uso: self._precio en lugar de self.precio


📝 FLUJO DE DATOS: ENTRADA → OBJETO → ALMACENAMIENTO → CONSULTA
================================================================================

1. input() del usuario
   ↓
2. Constructor crea objeto (valida con @setter)
   ↓
3. Objeto se registra en Restaurante (servicio)
   ↓
4. Se almacena en lista (self.productos o self.clientes)
   ↓
5. Se lista o busca mediante métodos del servicio


❓ PREGUNTAS FRECUENTES
================================================================================

P: ¿Necesito instalar dependencias externas?
R: No. Solo Python 3.7+ es necesario.

P: ¿Puedo usar este sistema sin el menú?
R: Sí. Usa "python ejemplo_uso.py" o importa los módulos en tu código.

P: ¿Cómo agrego nuevos productos/clientes?
R: En main.py, selecciona "1" (registrar) e ingresa los datos.

P: ¿Los datos persisten después de cerrar el programa?
R: No. Los datos están solo en memoria. Para persistencia, usa JSON/CSV/BD.

P: ¿Cómo modifico un producto existente?
R: Busca el producto, luego modifica sus atributos (usan @setter).

P: ¿Puedo tener dos productos con el mismo nombre?
R: No. El sistema evita duplicados por nombre.

P: ¿Cómo me aseguro de que los datos sean válidos?
R: El sistema valida automáticamente en constructores y setters.


🔧 EJEMPLOS DE USO PRÁCTICO
================================================================================

CREAR PRODUCTO:
    producto = Producto("Tacos", "Platos", 10.50)
    restaurante.registrar_producto(producto)

BUSCAR PRODUCTO:
    pizza = restaurante.buscar_producto_por_nombre("Pizza")
    if pizza:
        print(pizza.mostrar_informacion())

LISTAR PRODUCTOS:
    for prod in restaurante.listar_productos():
        print(f"{prod.nombre}: ${prod.precio}")

CREAR CLIENTE:
    cliente = Cliente("Pedro", "pedro@email.com", "CLI005")
    restaurante.registrar_cliente(cliente)

BUSCAR CLIENTE:
    cliente = restaurante.buscar_cliente_por_id("CLI001")
    if cliente:
        print(cliente.mostrar_informacion())

ESTADÍSTICAS:
    stats = restaurante.obtener_estadisticas()
    print(f"Precio promedio: ${stats['precio_promedio']:.2f}")
